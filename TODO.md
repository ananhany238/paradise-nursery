# Paradise Nursery Delivery Outcomes

## Landing page
- Include a background image, company name, paragraph about the company, and a Get Started button linking to the product listing page.

## Product listing
- Display at least six unique houseplants with thumbnail, name, price, and Add to Cart control.
- Group plants into at least three categories.
- Disable an item's Add to Cart button after it is added.
- Update the cart quantity dynamically after adding items.
- Provide navigation links to Home, Plants, and Cart.

## Shared header
- Show on both Product Listing and Shopping Cart pages.
- Include a shopping cart icon with the total number of items updated dynamically.
- Include navigation to the other application pages.

## Shopping cart
- Display each plant's thumbnail, name, unit price, quantity, and per-plant total cost.
- Provide increase, decrease, and delete controls for each plant type.
- Show the total number of plants and total cost of all items.
- Provide Continue Shopping navigation back to Plants.
- Provide a checkout button showing a Coming Soon message.

## Project delivery
- Use Redux for cart state with an inspectable CartSlice.jsx.
- Keep the project suitable for a public GitHub repository and GitHub Pages deployment.
